# Страны и города

Учебный проект на Next.js по заданию code.mu.

Страны и их города находятся в `data/countries.js`. Главная страница ведёт к странам, а страницы стран — к городам. Числовые данные округлены для учебного примера.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000.

Сборка: `npm run build`.
